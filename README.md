## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Lordshadow-afk/Dolo.git
   ```
2. **Setup environment variables:**
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
3. **Install dependencies:**
   ```bash
   flutter pub get
   ```
4. **Run the app:**
   ```bash
   flutter run
   ```

## 🧪 Testing
Run the test suite:
```bash
flutter test
```
